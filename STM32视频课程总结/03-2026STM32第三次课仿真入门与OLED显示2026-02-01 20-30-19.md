## 1. 按键程序中的逻辑错误与仿真调试

### 1.1 问题描述
- 上节课的按键程序（`K1.c` 和 `main.c`）存在**逻辑错误**：按键检测时，判断按键是否按下的条件写反了。
- 按键为上拉式，默认高电平（1），按下后变成低电平（0）。
- 错误示例：在消抖后误将条件写成了 `==1`（高电平），导致无法正确识别按键按下。*Screenshot-[00:41]*

### 1.2 错误发现方法
- **方法一：直接阅读代码**（不推荐，容易遗漏）。
- **方法二：使用仿真工具**（推荐），虽然编译无语法错误（0 error 0 warning），但可以通过仿真观察程序运行流程，发现逻辑错误。

### 1.3 修改建议
- 将 `key scan` 函数中判断按键是否按下的条件改为检测低电平 `==0`。
- 对于主循环中按键扫描的连续触发问题（连发/单发），若希望单次按键只触发一次动作，应将 `key scan` 函数的 `mode` 参数设为 `0`（单次触发模式），否则设为 `1` 会连续触发（类似游戏连发）。*Screenshot-[03:50]*

## 2. 仿真环境的使用方法

### 2.1 进入仿真界面
- 在 Keil MDK 中点击工具栏的 **"D" 按钮**（Debug/仿真）进入仿真界面。*Screenshot-[05:45]*

### 2.2 仿真界面关键元素
- **黄色箭头**：表示即将执行的下一条指令。
- **蓝色箭头**：鼠标点击位置，可直接跳转查看代码。
- **功能按钮**：*Screenshot-[06:00]*
  - **复位(RST)**：从头开始运行。
  - **全速运行(Run)**：程序连续执行。
  - **停止(Stop)**：暂停运行。
  - **单步进入(Step Into)**：进入函数内部逐条执行。
  - **单步跳过(Step Over)**：直接执行完当前函数，不进入内部。
  - **单步跳出(Step Out)**：跳出当前函数，返回调用处。

### 2.3 变量观察
- **鼠标悬停**：将鼠标移到变量上，可实时查看变量值。
- **添加观察窗口**：
  - 右键变量 → `Add to Watch1`，将变量加入 Watch 窗口。
  - 若 Watch 窗口默认在下方，可用鼠标拖拽至右侧或其他位置。*Screenshot-[12:36]*
- **全局变量便于实时观察**：将局部变量声明为全局变量（放在 `user code begin PV` 区域），可在全速运行时持续观察其值变化。

### 2.4 断点使用
- 左键点击代码行左侧灰色区域，可设置/取消**红色断点**。
- 程序运行到断点处会自动暂停，方便检查状态。
- 注意：**断点数量有限**，过多会报错 `can not set breakpoint`，可通过点击 `Kill All Breakpoints` 一键清空。*Screenshot-[17:19]*

### 2.5 优化等级问题
- 在 **魔法棒 (Options for Target) → C/C++ → Optimization** 中，务必选择 **Level 0 (-O0)**。
- 若优化等级过高，编译器可能会“优化掉”一些看似无用但实际必要的语句，导致仿真时某些代码无法执行。*Screenshot-[13:58]*

### 2.6 仿真经验技巧
- 仿真中若遇到弹窗报错无法关闭，可按 `Ctrl+Alt+Delete` 打开任务管理器结束任务后重新进入。*Screenshot-[23:16]*
- 仿真能有效发现逻辑错误，但偶尔可能存在软件小 bug，需结合板载运行结果综合判断。

## 3. OLED 显示屏的硬件连接与CubeMX配置

### 3.1 OLED 模块简介
- 分辨率：**128×64** 像素。
- 接口：**SPI 接口**（比 I²C 速度快），本课程使用 **SPI1**。
- 七根引脚：*Screenshot-[25:38]*
  - 电源：VCC (3.3V)、GND
  - 控制信号：
    - **SCK** (时钟) – PA5
    - **MOSI** (数据) – PB5
    - **RST** (复位) – PB4
    - **DC** (数据/命令选择) – PD2
    - **CS** (片选) – PC12

### 3.2 CubeMX引脚配置步骤
1. 打开 CubeMX 工程，进入 Pinout 视图。
2. 设置 **SPI1 模式**：`Connectivity → SPI1 → Mode: Transmit Only Master`（只发送主模式，因为 OLED 不返回数据）。*Screenshot-[29:38]*
3. 配置引脚：
   - PA5 → 自动被设为 `SPI1_SCK`（绿色表示配置完成）。
   - PB5 → 手动设为 `SPI1_MOSI`。
   - PB4 → 设为 `GPIO_Output`，并重命名为 `OLED_RST`（注意大小写，后续代码需一致）。
   - PD2 → 设为 `GPIO_Output`，重命名为 `OLED_DC`。
   - PC12 → 设为 `GPIO_Output`，重命名为 `OLED_CS`。*Screenshot-[38:44]*
4. 生成代码后，在 Keil 中打开项目，若报错缺少 `spi.h`，说明未生成 SPI 相关文件，需重新生成。

### 3.3 安装方向
- OLED 插针朝下，对准板子上的排母，**不要插反**（板子按钮朝下，USB 口朝上为正确方向）。*Screenshot-[26:01]*

## 4. OLED 显示驱动代码移植与使用

### 4.1 文件添加
- 将课程提供的三个文件复制到工程 `Drivers/User` 文件夹中：
  - `oled.c`
  - `oled.h`
  - `oled_font.h`
- 在 Keil 中，右键 `User` 组 → `Add Existing Files`，选择 `oled.c`（**不要添加 .h 文件**，靠路径搜索）。*Screenshot-[33:28]*

### 4.2 头文件路径
- 打开 **魔法棒 → C/C++ → Include Paths**，添加 `Drivers/User` 路径。
- 在 `main.c` 中 `#include "oled.h"`。*Screenshot-[49:17]*

### 4.3 初始化与基本流程
```c
// 在 main 函数初始化部分
OLED_Init();          // 初始化 OLED
OLED_Clear();         // 清屏（全黑）
OLED_Refresh_Gram();  // 将显存数据刷新到屏幕
```
- **重要**：所有显示操作后都必须调用 `OLED_Refresh_Gram()`，否则内容不会显示到屏幕。*Screenshot-[53:00]*

## 5. 常用显示函数详解

### 5.1 字符串显示
```c
OLED_ShowString(X, Y, "YourString", Size);
```
- **X**：水平坐标（列），范围 0~127，从左到右增大。
- **Y**：垂直坐标（行），范围 0~63，从上到下增大。
- **Size**：字号，可选 12、16、24。
  - 16号英文字符：宽8像素，高16像素。
  - 16号中文字符：宽16像素，高16像素（方形）。
- 示例：`OLED_ShowString(0, 0, "Love TVB", 16);` *Screenshot-[52:32]*

### 5.2 数字显示
```c
OLED_ShowNum(X, Y, number, length, Size);
```
- `number`：要显示的**变量**（不可直接写数字常量，需定义变量）。
- `length`：数字长度（位数），如显示两位数则 length=2。
- 示例：`OLED_ShowNum(0, 16, count, 2, 16);` *Screenshot-[59:23]*

### 5.3 清屏操作
- **全屏清除**：`OLED_Clear();` + `OLED_Refresh_Gram();`
- **局部清除**：在需要擦除的区域用空格字符串重新显示相同大小的内容。例如：*Screenshot-[56:08]*
  ```c
  OLED_ShowString(40, 0, "   ", 16);  // 三个空格覆盖掉原字符
  OLED_Refresh_Gram();
  ```

### 5.4 中文字符显示
- 需制作**字库**，参考之前视频教程。
- 提供的 `oled_font.h` 中已包含五个中文字“我是大帅哥”（索引0~4）。
- 使用函数：`OLED_ShowGBK(X, Y, index, Size, Mode);`（Mode=1 为正显，0为反白）。

### 5.5 图片/动画显示
- 使用函数 `OLED_ShowGF(image_array);`，图片数组需通过取模软件生成。
- 注意：图片数组过大会导致编译速度慢、下载速度慢，建议按需精简。*Screenshot-[53:21]*

## 6. 显示与按键的交互示例

### 6.1 按键清除显示内容
- 在按键处理中添加：
  ```c
  case 1:  // 假设是上键
      OLED_Clear();
      OLED_Refresh_Gram();
      break;
  case 2:  // 下键，局部清除
      OLED_ShowString(40, 0, "   ", 16);
      OLED_Refresh_Gram();
      break;
  ```

### 6.2 按键控制数字递增
- 定义全局变量 `u8 number = 0;`
- 在主循环中检测按键（如按一次左键让数字加1）：
  ```c
  case 3:  // 左键
      number++;
      break;
  // 在 switch 结束后统一调用：
  OLED_ShowNum(0, 16, number, 2, 16);
  OLED_Refresh_Gram();
  ```
- 注意：若需要连续变化（按住不放），需将 `key scan` 的 mode 参数设为 1。*Screenshot-[03:36]*

## 7. 作业要求与建议

- **基础任务**：在 OLED 屏幕上显示自己的名字，并能通过按键将其清除或修改。
- **进阶任务**：
  - 显示数字，通过按键实现加/减/清零功能。
  - 结合按键与 OLED，实现简易计数器（测试按键响应速度）。
  - 尝试显示图片或简单动画（参考之前的取模视频）。
- **注意事项**：
  - 每次修改显示后都必须调用 `OLED_Refresh_Gram()`。
  - 避免在 `while(1)` 中反复执行 `OLED_Init()` 和 `OLED_Clear()` 导致闪烁。
  - 编译前检查优化等级是否为 Level 0，防止代码被意外优化。
