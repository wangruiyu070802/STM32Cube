## 1. GPIO 基本概念与作用

- **GPIO**（General Purpose Input/Output）是通用的输入输出接口。
- 作用：
  - **输入**：信号从外界（如传感器状态、电平信号）传入控制器内部，用于数据传递或状态感知。
  - **输出**：控制器（如 STM32F401 芯片）向外界发送信号，用于控制（如继电器、LED 灯）。

## 2. GPIO 引脚命名规则

- 命名格式：`P`（Port）开头，后跟字母（A、B、C 等）表示端口，再跟数字（0~15）表示引脚号。
- 示例：`PA0`、`PA8`、`PB9`、`PC13` 等。
- 常见的端口：GPIOA、GPIOB、GPIOC。

## 3. GPIO 工作模式

- **输入模式**（三种常用）：
  - 普通输入（浮空输入）
  - 上拉输入（内部上拉电阻）
  - 下拉输入（内部下拉电阻）
- **输出模式**（两种常用）：
  - 推挽输出（Push-Pull）
  - 开漏输出（Open-Drain）—— 常用于总线通信。

## 4. 输出函数详解

- **`HAL_GPIO_WritePin(GPIOx, GPIO_Pin_n, GPIO_PIN_state)`**：向指定引脚写入高或低电平。
  - 参数1：端口（如 `GPIOA`）
  - 参数2：引脚（如 `GPIO_PIN_8`）
  - 参数3：状态（`GPIO_PIN_SET` 高电平，`GPIO_PIN_RESET` 低电平）
  - 高电平 ≈ 3.3V（VDD），低电平 ≈ 0V（GND）。
- **`HAL_GPIO_TogglePin(GPIOx, GPIO_Pin_n)`**：翻转引脚电平（高变低，低变高）。
  - 仅需端口和引脚两个参数，无需指定状态。

## 5. 输入函数详解

- **`HAL_GPIO_ReadPin(GPIOx, GPIO_Pin_n)`**：读取指定引脚的电平状态。
  - 返回值类型：`GPIO_PinState`，取值为 `GPIO_PIN_SET`（高电平）或 `GPIO_PIN_RESET`（低电平）。
  - `GPIOx`       -> 端口号
  - `GPIO_PIN_x`  -> 引脚号
## 6. GPIO 翻转函数

- **`HAL_GPIO_TogglePin(GPIOx, GPIO_Pin)`**：每次调用将引脚状态取反。
- 适用于快速改变输出状态，如 LED 闪烁。

示例用法：
  ```c
  HAL_GPIO_WritePin(GPIOA, GPIO_PIN_O, GPIO_PIN_SET);
  HAL_GPIO_TogglePin(GPIOC，GPIO_PIN_1);
  uint8_t ST = HAL_GPIO_ReadPin(GPIOA, GPIO_PIN_8);
  ```
## 7. LED 驱动原理与电路

- **LED（发光二极管）** 具有正负极，正向导通（正极高电平，负极低电平）才发光。
- **驱动条件**：需要电源正极、限流电阻、LED、地（GND）组成回路。
- **两种驱动方式**：
  - **高电平驱动**：IO 口输出高电平时，电流经电阻 → LED → GND，灯亮；IO 口低电平时灯灭。
  - **低电平驱动**：IO 口输出低电平时，电流从 VCC → 电阻 → LED → IO 口，灯亮；IO 口高电平时灯灭。
- **本开发板 LED 电路**（以图示为例）：IO 口 → 1.5kΩ 电阻 → LED（正极接电阻，负极接地）——属于**高电平驱动**（IO 口高电平灯亮，低电平灯灭）。
- 限流电阻计算示例：假设 LED 压降约 1.7V，电源 3.3V，电阻 1kΩ，则电流 ≈ (3.3-1.7)/1000 = 1.6mA。

## 8. 工程创建与代码规范

- 将基础工程（如 Demo）复制并重命名（如 `Key_And_LED`）。
- 在 CubeMX 中配置 GPIO：
  - LED 引脚设为 **Output**，默认电平可选择 `Low`（上电不亮）。
  - 按键引脚设为 **Input**，并选择 **Pull-up**（上拉输入）。
- 代码必须写在 `USER CODE BEGIN` 和 `USER CODE END` 之间，否则重新生成代码时会丢失。
- 程序结构：
  - 初始化部分（`HAL_Init` → 时钟初始化 → GPIO 初始化 → 用户初始化）只执行一次。
  - 主循环 `while(1)` 为死循环，反复执行任务代码。
- 书写规范：使用 Tab 缩进，不要顶格写，提高可读性。

## 9. 延时函数的使用

- 提供 `delay.c` 和 `delay.h` 文件（需自行添加到工程）。
- 使用步骤：
  1. 将 `delay.c` 和 `delay.h` 复制到工程 `Drivers/User` 目录下。
  2. 在 IDE 中新建分组（如 `User`），添加 `delay.c`。
  3. 在 `main.c` 中包含 `delay.h`。
  4. 调用 `Delay_Init(SystemCoreClock)` 初始化（SystemCoreClock 通常为 84MHz）。
  5. 使用 `Delay_us(微秒)` 或 `Delay_ms(毫秒)` 实现精确延时。
- 示例：`Delay_ms(200);` 延时 200 毫秒。

## 10. 按键原理与电路分析

- **按键类型**：
  - **上拉按键**：IO 口通过上拉电阻接 VCC，按键另一端接地。未按下时 IO 口为高电平，按下时为低电平。
  - **下拉按键**：IO 口通过下拉电阻接地，按键另一端接 VCC。未按下时 IO 口为低电平，按下时为高电平。
- **本开发板按键电路**：仅有按键和地，无外部上拉电阻 —— 应使用 IO 口内部的**上拉模式**（`GPIO_PULLUP`）。
- 如需外接上拉电阻，必须在按键与 VCC 之间串联电阻（否则按下时电源短路）。

## 11. 按键扫描代码实现

- 提供 `key.c` 和 `key.h`（含按键扫描函数）。
- 按键扫描函数（如 `Key_Scan()`）返回按键值（1~N），内部包含：
  - 读取对应引脚电平。
  - 软件去抖（延时约 10ms 后再次确认）。
- 返回值定义示例：
  ```c
  #define KEY_PRESS_1 1
  #define KEY_PRESS_2 2
  // ...
  ```
- 使用 `switch-case` 语句根据返回值执行不同操作。

## 12. 综合实验：按键控制 LED

- 实验目的：按下不同按键，控制不同 LED 的亮灭或闪烁。
- 实现步骤：
  1. 在 `main.c` 中包含 `key.h` 和 `delay.h`。
  2. 初始化延时函数：`Delay_Init(84);`（84MHz）。
  3. 在主循环中调用按键扫描，获取键值。
  4. 根据键值执行：
     - 例如：按键1 → 翻转 LED1；按键2 → 翻转 LED2；...
     - 剩余按键可自定义花样（如流水灯、全亮、全灭等）。
- 注意：每次按键操作后应添加适当延时，避免误触发。
