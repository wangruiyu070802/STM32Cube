### 机械臂结构与组装要点
- **多功能支架**：用于将舵机固定到平面上。支架侧面有孔，可固定在底板上。舵机通过多功能支架固定后，其舵盘再连接其他结构。
- **长U型支架**：两个长U型支架可以对接到一起，用于连接不同部件。
- **组装顺序要求**：在组装机械臂时，必须根据每个关节期望的转动角度范围来决定如何安装舵机和支架。

### 舵机初始化与安装技巧
#### 初始化到90度的意义
- 对于 **180度舵机**，其运动范围是0°到180°，中间位置是90°。
- 安装前，**必须先将舵机电调初始化到90度**。这样，安装好结构件后，舵机才能向左右各转动90度。
- **错误示例**：如果不进行初始化，或者初始化后胡乱安装支架（例如将本应竖直安装的U型支架水平安装），会导致实际运动范围与预期完全不符。

#### 安装姿态与角度范围
- 初始化到90°后，根据结构件所需的运动姿态进行安装。
- 例如，如果希望某个关节在斜向下45°到斜向上45°的范围内运动，就将舵机初始化到90°后，将支架呈这个中间角度安装上去。这样它就能向上和向下各转90°，覆盖目标范围。

#### 上电初始化与安全性
- **静态姿态**：程序中的舵机初始化角度，应设置为机械臂在断电后自然垂落、稳定且不会晃动的姿态。
- **安全原则**：这样做的目的是保证上电瞬间，舵机**几乎不转动**。如果初始角度与物理静态角度差异过大，上电时舵机会全速猛地转动，可能造成危险（如打到人）或损坏设备。

### 舵机控制：程序设计与基础函数
#### PWM配置与舵机控制原理
- **控制函数**：使用 `PWM_Start` 启动PWM波输出，用 `Set_Compare` 函数设置占空比，从而控制舵机角度。
- **PWM信号规格**：
  - 周期：**20毫秒 (ms)**
  - 高电平时间：**0.5ms 对应 0°**，**2.5ms 对应 180°**。
  - 中间任意角度可通过公式计算。
- **时钟配置**：为获得更高控制精度，在 STM32CubeMX 中设置定时器（如Timer 3）的预分频系数（PSC）为 `83`（这样每个计数单位时间为1微秒）。自动重载值（ARR）设置为 `19999`，刚好对应20000微秒（20ms）的周期。

#### 电源需求与稳定性
- **电源要求**：舵机需要充足且稳定的电源。以一个25kg舵机为例，正常工作时电流约为**1安培 (A)**，电压通常为**5V**或**6V**，堵转时电流可能飙升至1.5A或更高。
- **供电不足现象**：如果电流不够，电压会被拉低，可能导致STM32主控重启。现象为：舵机一动，整个系统板上的指示灯变暗，主控反复重启，舵机不断抽搐。

#### 创建舵机控制模块
- 新建 `servo.c` 和 `servo.h` 文件，加入工程。
- 在 `servo.h` 中需要包含 `main.h`、`cs.h`（用于类型缩写）、`tim.h`（定时器相关函数）。
- 创建初始化函数 `servo_Init`，其核心任务是：
  1. 调用 `HAL_TIM_PWM_Start(&htimx, TIM_CHANNEL_x)` 启动所有用到的PWM通道。
  2. 根据需要设定舵机的初始角度。

#### 角度与脉宽换算公式
将角度（以180度舵机为例）换算为 `Set_Compare` 函数的 `pulse` 值的公式：
```
Pulse (微秒) = 500 + (角度 / 180.0) * 2000
```
其中，500是0°对应的0.5ms（500μs），2000是180°到0°的高电平宽度差（2500μs - 500μs）。在进行整数运算时，建议**先乘后除**`(2000 * 角度) / 180`，以减少精度损失。

### 代码优化：利用结构体管理多路舵机
为了更优雅地管理多个舵机，可以使用**结构体数组**。AI辅助生成的代码示例如下：
```c
// 舵机配置结构体
typedef struct {
  TIM_HandleTypeDef *htim; // 定时器
  uint32_t Channel;      // 通道
  float InitAngle;       // 初始角度
} Servo_Config;

// 定义一个结构体数组，存放我们要初始化的舵机
Servo_Config my_servos[] = {
  {&htim1, TIM_CHANNEL_1, 90.0f}, // 舵机1: Timer 1, 通道1, 初始90度
  {&htim1, TIM_CHANNEL_2, 0.0f},  // 舵机2: Timer 1, 通道2, 初始0度
  {&htim3, TIM_CHANNEL_1, 45.0f}  // 舵机3: Timer 3, 通道1, 初始45度
};

// 通用初始化函数
void Servo_Init(Servo_Config *servos, uint8_t count) {
  for (int i = 0; i < count; i++) {
    // 启动PWM
    HAL_TIM_PWM_Start(servos[i].htim, servos[i].Channel);
    // 计算并设置初始角度对应的脉宽值
    uint16_t pulse = (uint16_t)(500 + (servos[i].InitAngle / 180.0f) * 2000);
    __HAL_TIM_SET_COMPARE(servos[i].htim, servos[i].Channel, pulse);
  }
}

// 在main函数中调用
// 需要先声明外部变量: extern Servo_Config my_servos[];
Servo_Init(my_servos, 3); // 初始化数组中的3个舵机
HAL_Delay(1000); // 等待舵机转动到初始位置（仅初始化时使用）
```
这个方法的优点是灵活，想用几个舵机就在数组里定义几个。

### 舵机控制进阶讨论
#### 全速转动的弊端
- 直接使用 `Set_Compare` 跳变角度会让舵机**全速转动**。这会带来问题：
  1. **电流冲击**：瞬间大电流可能导致电压跌落，系统重启。
  2. **机械冲击**：速度快、惯性大，可能刹不住导致过冲，损坏齿轮或结构，甚至伤人。

#### 避免阻塞式延时
- **阻塞式延时**（如 `HAL_Delay`）是糟糕的代码实践，它会浪费宝贵的CPU算力。在舵机转动到位的等待时间内，CPU本可以处理其他任务。
- **更好的方法**：通过定时器中断，以固定的微小步进（例如每10ms）逐步调整占空比，从而实现**慢速、平滑**的控制，甚至可以实现加减速算法（梯形加减速或S形加减速）。

### 硬件接线与故障排查
#### 接口与电源连接
- **板载信号指示**：本开发板的8路舵机PWM信号输出都对应一个LED指示灯。有信号时灯会亮，可以用来初步判断是否有PWM输出。
- **供电**：必须使用外部DC 12V电源输入，通过板载可调电源模块为舵机提供5V/6V电源。
- **接线**：舵机的三根线（通常是红黄黑）要按照板子标注的颜色正确连接，切勿插错。

#### 常见故障与处理
- **舵机不受控乱动**：大概率是供电问题，电流不够。
- **舵机完全不动**：检查供电是否正常，以及PWM信号灯是否亮起。用示波器可检查信号是否准确。
- **舵机360°狂转不停**：舵机内部的**电位器（角度传感器）失效**，导致无法感知角度。断电后用万用表电阻档测量电位器阻值确认。
- **舵机电机发烫但不转**：可能是**电机与齿轮箱脱离**（电机空转但轴不转）。这会导致控制算法以为力矩不够而持续加大电压，最终烧毁电机。一旦发现此情况，**必须立刻断电**。
- **手动拧不动舵机**：齿轮箱卡死，可能是齿轮崩裂或安装错位。应立即停用并检修。

### 安全与操作铁律
- **严禁热插拔**：在电路板通电（指示灯亮）时，绝对禁止插拔舵机或其他设备，极易烧毁芯片或电路。
- **避免手拧舵机**：强行手动拧舵机轴，不仅可能损坏齿轮，还可能让电机发电，产生的高电压可能反向击穿电路。
- **先断电，后操作**：任何连接、调整工作前，务必先断开所有电源。
- **启动姿态要安全**：程序上电初始化的姿态，务必与硬件断电时的自然静止姿态一致，防止设备突然动作伤人。
