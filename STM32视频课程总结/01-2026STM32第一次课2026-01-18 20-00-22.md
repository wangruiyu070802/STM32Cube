## 1. 开发板硬件介绍

### 1.1 主控芯片
- 使用 **STM32F401RC** 芯片（ARM Cortex-M4）。
- 负责整个电路板的控制。

### 1.2 仿真器芯片
- 位于板子上的另一颗芯片（STM32F103等），通过 **USB口** 连接电脑。
- 功能：
  - 下载程序到主控芯片
  - 在线仿真调试（单步运行、查看状态）
  - 虚拟串口：模拟串口与主控芯片通信

### 1.3 板载外设
- **蜂鸣器**：贴片蜂鸣器
- **排针**：两侧排针引出主控芯片I/O引脚，包含3.3V、GND等电源引脚
- **外部电源接口（EXP）**：通过DC口供电，最高支持18V（建议12V锂电池），不能超过18V，否则会烧毁芯片
- **舵机接口**：8路舵机接口（信号-电源-GND），电源电压可通过程序调节（利用PB10控制FB引脚），初始无输出需配置
- **LED指示灯**：8个LED（高电平点亮），对应8路舵机信号状态显示
- **OLED屏幕接口**：直接插拔使用
- **无线模块接口**：用于远距离通信（如蝶形赛题）
- **五向按键**：上下左右+按下，共5个动作；加上其他按键共10个按键，用于控制机械臂等
- **复位按钮**：RESET
- **串口接口**：串口2（RX2/TX2）和串口6（RX6/TX6），带GND
- **电源转换**：
  - 5V输出（约2A），由USB或DC供电转换而来
  - 可调电压输出（用于舵机），由MP56528芯片控制，最高5A
  - 3.3V输出（约1.3A）

### 1.4 上电指示灯
- 仿真器灯：常亮，工作时闪烁
- 5V灯：亮起表示供电正常
- 可调电压灯：需程序控制才亮

## 2. 软件环境准备

### 2.1 所需软件
- **STM32CubeMX**：可视化配置工具，生成初始化代码
- **Keil MDK (uVision5)**：集成开发环境（IDE），编译下载
- **ST-Link驱动**：确保仿真器被电脑识别

### 2.2 软件检查与设置
#### Keil MDK 许可证检查
- 打开 Keil → `File` → `License Management`
- 必须看到 `MDK-ARM Plus` 及有效期至2032年（需破解，以管理员身份运行破解工具）

#### STM32CubeMX 设置
- 首次使用需登录ST账号（`Help → Manage embedded software packs`）
- 确保 `STM32F4` 系列Pack已安装（绿色方块），否则勾选并点击 `Install`

#### 驱动安装
- 如果电脑未识别ST-Link，需安装驱动：解压 `stlink驱动` 文件夹 → 运行 `USB driver` 安装程序
- 安装后插入板子，应出现虚拟U盘（`undefined`）

## 3. 新建工程与配置

### 3.1 打开CubeMX并选择芯片
- 双击 `STM32CubeMX` → 点击 `Access to MCU Selector`
- 输入芯片型号：`STM32F401RC` → 选择 `STM32F401RCT6` → 双击

### 3.2 系统设置（System Core）
#### SYS（Debug）
- 找到 `SYS` → `Debug` 必须选择 **Serial Wire (SW)**，不能选 `Disable`
  - 否则下载一次后仿真器失效，需用工具擦除芯片才能恢复

#### RCC（复位与时钟控制）
- `HSE`（高速外部时钟）：选择 `Bypass Clock Source`
  - 原因：板子上未焊接晶振，时钟由仿真器芯片提供8MHz信号
  - 若板子有外部晶振则选 `Crystal/Ceramic Resonator`
- `LSE`（低速外部时钟）：选择 `Disabled`（板上未接32.768kHz晶振）

### 3.3 时钟配置（Clock Configuration）
- 进入 `Clock Configuration` 页面
- 输入 `HSE` 频率：8 MHz（与仿真器输出一致）
- 配置PLL倍频链路：
  - 8 MHz ÷ 8 = 1 MHz
  - 1 MHz × 168 = 168 MHz
  - 168 MHz ÷ 2 = 84 MHz（系统时钟 `HCLK`）
  - 注意：`APB1` 时钟不能超过42 MHz，需选择 `/2` 分频
- 最终 `System Clock` 为 **84 MHz**

### 3.4 GPIO配置（点亮LED）
- 在芯片引脚图上找到 `PC9`（对应板子上第一个LED `LD1`）
  - 鼠标左键点击引脚 → 选择 `GPIO_Output`
  - 右击引脚 → `Enter User Label` → 输入 `LD1`
- 同样设置 `PC8` → 标签 `LD2`
- **配置输出电平**：
  - 进入 `System Core → GPIO`，在列表中设置：
    - `LD1` (PC9)：`Output Level` 设为 `High`（上电亮）
    - `LD2` (PC8)：`Output Level` 设为 `Low`（上电灭）
  - 其余6个LED（PC7、PC6、PA6等）自行设置，实现一亮一灭交替

## 4. 时钟系统配置

### 4.1 时钟源选择依据
- 根据原理图：主控芯片 `OSC_IN` 引脚通过零欧电阻连接至仿真器芯片的 `MCO` 引脚，该引脚输出8MHz时钟信号
- 因此 `HSE` 选择 **Bypass**（外部时钟信号输入），而非晶振

### 4.2 关键设置步骤
| 参数 | 值 | 说明 |
|------|-----|------|
| HSE输入频率 | 8 MHz | 仿真器晶振频率 |
| PLL_M | 8 | 8 ÷ 8 = 1 MHz |
| PLL_N | 168 | 1 × 168 = 168 MHz |
| PLL_P | 2 | 168 ÷ 2 = 84 MHz |
| 系统时钟 | 84 MHz | 最终主频 |
| APB1分频 | /2 | 确保APB1≤42 MHz |

## 5. GPIO与LED控制

### 5.1 原理简述
- 每个LED串联限流电阻，一端接GND，另一端接GPIO引脚
- GPIO输出高电平（3.3V）→ LED亮；输出低电平（0V）→ LED灭

### 5.2 标签命名
- 在CubeMX中为引脚设置 `User Label`，如 `LD1`、`LD2`…`LD8`
- 命名区分大小写，后续编程中需完全匹配

### 5.3 初始化输出电平
- 在 `GPIO` 配置页面，可设置每个引脚初始输出状态（`High` 或 `Low`）
- 本次任务：实现8个LED中有亮有灭，建议4个亮4个灭

## 6. 代码生成与工程设置

### 6.1 生成代码
- 进入 `Project Manager` → 设置：
  - `Project Location`：**英文路径**（如 `F:\embedded system\2026\`）
  - `Project Name`：`demo`（英文）
  - `Toolchain / IDE`：选择 **MDK-ARM**
  - `Code Generator` → 勾选 `Generate peripheral initialization as a pair of '.c/.h' files per peripheral`
- 点击 `GENERATE CODE`

### 6.2 打开工程
- 生成后弹出窗口，选择 `Open Project` → 自动打开Keil

### 6.3 Keil工程设置
#### Target 选项
- 点击魔法棒图标 → `Target` → 勾选 `Use MicroLIB`
  - 后续串口等方便使用

#### C/C++ 选项
- `Optimization`：选择 **Level 0 (-O0)**，不优化，避免调试问题
- `Include Paths`：添加自定义文件夹（如下）

#### 添加用户文件夹
- 在工程目录下 `Drivers` 文件夹中新建 `User` 文件夹（用于存放用户 *.c/*.h 文件）
- 在Keil中 `C/C++ → Include Paths → New` → 选择该 `User` 文件夹

#### 编码设置
- `Edit → Configuration → Editor → Encoding`：选择 `Chinese GB2312 (Simplified)`
- 确认 `Text Completion` 功能正常（代码补全）

## 7. 程序下载与调试

### 7.1 编译
- 点击 `Build` 按钮（或按F7），查看输出窗口零错误零警告
- 注意：零错误不代表功能正确，仅表示语法无误

### 7.2 下载
- 点击 `Download` 按钮（或按F8）
- 成功标志：输出 `"Flash Load finished"`、`"Erase Done"`、`"Programming Done"`、`"Verify OK"`

### 7.3 运行
- 下载后需按下板子上的 **RESET** 按钮，程序才会开始执行
- 观察LED状态：LD1（PC9）应点亮，LD2（PC8）应熄灭

### 7.4 调试注意事项
- Keil的 `Debug` 选项卡需选择 `ST-Link Debugger`
- 点击 `Settings` 确认左侧出现 `ST-Link` 设备，右侧出现目标芯片（如 `STM32F401RC`）
- 若右侧无芯片：可能芯片被锁或烧坏，需解锁或更换

## 9. 常见问题与解决方法

| 问题 | 原因 | 解决方法 |
|------|------|----------|
| Keil启动时跳进度条 | 缺少STM32F4系列Pack | 安装 `Keil.STM32F4xx_DFP` 包 |
| 仿真器不识别 | 驱动未装 / 线接触不良 / 线坏 | 安装ST-Link驱动，换线 |
| 右侧识别不到主控芯片 | 芯片被锁 / 芯片烧坏 | 按住RESET，用工具连接后全片擦除；若发烫则更换芯片 |
| 程序下载后灯不亮 | 未复位 | 手动按RESET按钮 |
| CubeMX生成的代码中用户代码被覆盖 | 代码未写在 `USER CODE BEGIN/END` 之间 | 必须写在对应注释块内 |
| 编译错误：找不到头文件 | 包含路径未设置 | 检查Include Paths |
| IDE中文显示乱码 | 编码设置不对 | 设置编辑器编码为GB2312 |
