## 函数中变量的定义方式

### 问题背景
在定时器中断回调函数（HAL_TIM_PeriodElapsedCallback）中，若想对中断进入次数进行计数，通常会在函数内部定义一个局部变量（如 `u int8t counter`），然后执行 `counter++` 并对其取模（如 `%8`）控制 8 个 LED 灯翻转。

### 局部变量的缺陷
- **每次进入函数都会重新定义并赋初值**（如 `counter = 0`），因此 `counter` 永远只能从 0 变为 1，无法递增。
- 若不赋初值，变量内存中的值是随机数（如 `0x74`），行为不可控。

### 解决方案

1. **使用 `static` 关键字**（静态局部变量）
   - 语法：`static u int8t counter = 0;`
   - 静态变量在第一次定义时赋初值，之后每次进入函数会沿用上一次的值。
   - 代码示例：
     ```c
     void HAL_TIM_PeriodElapsedCallback(TIM_HandleTypeDef *htim)
     {
         static u int8t counter = 0;
         counter++;
         // 对 counter 取模判断灯翻转
     }
     ```

2. **使用全局变量**
   - 将变量定义在函数外部（如文件顶部），此时 `static` 可省略。
   - 全局变量在整个程序运行期间保持其值。
   - 代码示例：
     ```c
     u int8t counter = 0;
     void HAL_TIM_PeriodElapsedCallback(TIM_HandleTypeDef *htim)
     {
         counter++;
         // 对 counter 取模判断灯翻转
     }
     ```

### 结论
- 若希望函数每次调用时变量值能保留上次的结果，应使用 `static` 静态变量或全局变量。
- 若希望变量每次进入函数时都从初值开始，则直接定义局部变量即可。

## PWM 基本原理

### 定义
- **PWM**：脉冲宽度调制，周期固定、高电平持续时间可调的波形。
- 英文：Pulse Width Modulation。
- 应用领域：电机转速控制、灯亮度控制、电源功率控制、舵机控制等。

### 基本参数
- **周期**：高电平时间（t_on） + 低电平时间（t_off） = 固定值。
- **占空比**：高电平时间 ÷ 周期 × 100%，表示高电平占整个周期的比例。
- 示例：周期 100ms，高电平 50ms → 占空比 50%。

### 与定时器的关系
- 定时器从 0 开始逐次加 1，每次加 1 的单位时间由 `PSC`（预分频系数）决定。
  - 单位时间 = 1 / (定时器时钟 / (PSC + 1))
  - 例如：84MHz 时钟，PSC = 83 → 1MHz → 单位时间 1μs。
- 定时器计数值达到 `Counter Period`（重装载值，也称 ARR）后归零，完成一个周期。
- **CCR**（捕获/比较寄存器）决定高电平的结束时刻：当计数小于 CCR 时输出高电平，达到 CCR 后输出低电平（或相反，取决于极性配置）。
- 调节 CCR 值即可改变占空比。

### 关键寄存器与参数
- `PSC`：预分频系数
- `Counter Period`（ARR）：周期值
- `Pulse`（CCR）：占空比控制值
- 三个参数的单位时间一致，均基于定时器时钟。

## 本次课程实验：通过 PWM 控制电压输出

### 硬件目标
- 使用 STM32 的 PB10 引脚输出 PWM 波。
- PWM 波经过低通滤波后连接至 TPS56528 芯片的 FB 端，从而控制板上的“正六伏”输出端（实际可调）。
- 外部电源（4.5V – 18V）通过 DC 口接入板子，经 TPS56528 转换为可调电压输出。

### 工程配置（CubeMX）
1. 设置 PB10 为 `TIM2_CH3` 输出。
   - Pinout & Configuration → Timers → TIM2 → Clock Source → Internal Clock（84 MHz）。
   - Channel3 → PWM Generation CH3。
2. 参数设置：
   - Prescaler (PSC): 83（分频后 1MHz）
   - Counter Period（ARR）: 20（决定周期步进数，此处设为 20 档）
   - Pulse: 初始设为 0（占空比 0%）
3. 不使能中断（NVIC Settings 无需设置）。
4. 生成代码。

### 核心函数
- `HAL_TIM_PWM_Start(&htim2, TIM_CHANNEL_3)`：启动 PWM 输出。
- `__HAL_TIM_SET_COMPARE(&htim2, TIM_CHANNEL_3, pulse_value)`：设置 CCR（即 Pulse 值），改变占空比。

### 软件实现（按键调节电压）
- 定义全局变量 `power_level`（uint8_t，初始 0）。
- 按键 1（上）增加占空比：`if(power_level < 20) { power_level++; __HAL_TIM_SET_COMPARE(&htim2, TIM_CHANNEL_3, power_level); }`
- 按键 2（下）减少占空比：`if(power_level > 0) { power_level--; __HAL_TIM_SET_COMPARE(&htim2, TIM_CHANNEL_3, power_level); }`
- 显示：在 OLED 或 LCD 上显示 `power_level` 数值（0~20），方便观察。

### 注意事项
- `Counter Period` 设 20 时，Pulse 有效范围为 0 ~ 20（0 对应全低电平，20 对应全高电平）。
- 若超出范围，输出行为不可控。
- 占空比与输出成反比（具体需实测，视频中提及“pass 越大输出电压越小”）。

### 作业要求
1. 将外部 DC 电源（≤18V）插入板子。
2. 用万用表测量板上“六伏”引脚与 GND 之间的电压。
3. 按下按键，观察电压变化：最小值约 0.6V，最大值约 7V（与输入电压有关）。
4. 可调整 `Counter Period` 的值（例如 100）来获得更精细的调节档位，同时修改程序中的边界判断。

## 硬件接线与万用表使用

### DC 电源接口
- 板子上黑色 DC 口：中间为正极（+），外部为负极（-）。
- 可用可调电源（12V 左右）、锂电池（12V）或 DC 适配器供电。
- **注意**：输入电压不能超过 18V，否则会烧毁 TPS56528 芯片。

### 杜邦线使用要点
- 杜邦线公头（针状）插母头（孔状），插入要用力且有明显的阻塞感，否则接触不良。
- 若插上后松动，可用螺丝刀等硬物轻压母头内的金属簧片。
- 杜邦线承载电流有限（约 1A），大电流应用需用硅胶线。

### 万用表操作
- **档位选择**：测直流电压时用直流电压档（V 横线 三个点），量程应略高于被测电压（如 20V 档）。
- **表笔插孔**：黑表笔插 `COM` 端，红表笔插 `VΩmA` 端（测电压、电阻、电容时）。
- **超量程提示**：显示 `OF`（OverFlow）。
- **蜂鸣器档**（二极管/蜂鸣器档）：用于测试导线是否导通（短路时蜂鸣器响）。

### 安全警告
- 测量板上“六伏”引脚时，表笔只能接触该引脚，切勿碰到相邻引脚（可能造成短路或烧毁主芯片）。
- 建议用杜邦母头引出导线后再用表笔测量，更安全。
