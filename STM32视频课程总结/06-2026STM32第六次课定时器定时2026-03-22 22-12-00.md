## 定时器的两大功能

1. **定时**：计数间隔已知（例如每1秒数一个数），通过计数值可推算出时间。
2. **计数**：计数间隔未知，只记录脉冲个数。

区分关键：是否知道数数的间隔。知道间隔 → 定时器；不知道 → 计数器。

---

## 定时器分类与特点

- **基本定时器**：只有最基本的定时功能。
- **通用定时器**：除定时外，可产生 PWM 信号、输出比较（控制电机）、输入捕获（测量外部信号）。
- **高级定时器**：具备通用+基本定时器所有功能，额外支持互补信号输出和紧急刹车功能。

**本视频使用芯片**：STM32F40RC  
该芯片无基本定时器，仅有高级和通用定时器。视频中将所有定时器按通用定时器讲解，重点用于 PWM 输出和电机驱动。

## 定时器位数与通道

| 位数 | 计量范围 | 例子 |
|------|----------|------|
| 16位 | 0 ~ \(2^{16} - 1 = 65535\) | 大部分定时器 |
| 32位 | 0 ~ 4294967295（约42.9亿） | 仅2个 |

通道数量示例：
- TIM2：4个通道
- TIM9：2个通道
- TIM10、TIM11：各1个通道

所有定时器的**基础时钟**均为 **84 MHz**（与CPU主频一致）。

---

## 定时器时钟与分频（PSC）

- 内部时钟源：84 MHz
- 分频目的：降低计数频率，使单位时间变长，避免计数值溢出过快。
- 分频公式：  
  \[
  \text{实际分频系数} = \text{PSC} + 1
  \]
  分频后频率：  
  \[
  f_{\text{单位}} = \frac{84\,\text{MHz}}{\text{PSC} + 1}
  \]

- **常用 PSC 值**（加1后得到整数分频）：

| PSC 设置值 | 实际分频 | 分频后频率 | 单位时间 |
|------------|----------|------------|----------|
| 83         | 84       | 1 MHz      | 1 μs     |
| 839        | 840      | 0.1 MHz    | 10 μs    |
| 8399       | 8400     | 0.01 MHz   | 100 μs   |

> 注意：PSC 设置值在 CubeMX 中直接填写，内部自动加1。

---

## 单位时间与周期计算

\[
T = \frac{1}{f}
\]

- 1 MHz → \(T = 1\,\mu s\)
- 0.1 MHz → \(T = 10\,\mu s\)
- 0.01 MHz → \(T = 100\,\mu s\)

**常用单位**：微秒（μs，\(10^{-6}\)秒）

---

## 计数值与定时时长计算

定时器从 **0** 开始向上计数，到达**目标值（ARR）**后溢出（产生中断或自动重装载）。

- 计数值 = 目标值 + 1（因为从0开始数）
- 定时时长 = 单位时间 × 计数值

**示例**：
- PSC = 83 → 单位时间 1 μs
- ARR = 9 → 计数值 = 10 → 定时时长 = 10 μs

**长定时方法**：若无法一次完成（如定时10秒），可采用多次定时组合（如每次1秒，重复10次）。

---

## 定时器的计数方式

视频中只使用 **向上计数**（从0开始向上计到目标值）。  
- 目标值也称为 **自动重装载值（ARR）**  
- 溢出后自动从0重新开始，实现循环定时（类似每日闹钟）。

---

## 定时器中断相关函数

| 函数 | 作用 |
|------|------|
| `HAL_TIM_Base_Start_IT(&htimX)` | 以中断方式启动定时器基础功能 |
| `HAL_TIM_Base_Stop_IT(&htimX)` | 关闭中断方式的定时器 |

启动后，定时器会周期性溢出，每次溢出时进入中断回调函数。

---

## 中断回调函数的使用

1. 通用中断处理函数：`HAL_TIM_IRQHandler()`（CubeMX自动生成）
2. 用户需实现**回调函数**（用户自定义）：
   \[
   \text{HAL\_TIM\_PeriodElapsedCallback(TIM\_HandleTypeDef *htim)}
   \]

**回调函数内部判定中断来源**（因为所有定时器共用同一个回调函数名）：
```c
if (htim->Instance == TIM10) {
    // 执行定时器10相关的操作
    HAL_GPIO_TogglePin(LD1_GPIO_Port, LD1_Pin);
}
```
- 必须通过 `htim->Instance` 判断是哪个定时器触发的。
- 回调用函数若未关闭定时器，将自动循环执行。

## 实战作业：0.1秒闪烁LED

**要求**：控制 LED 每 0.1 秒翻转一次（亮0.1秒→灭0.1秒）。

### 步骤

1. **计算参数**  
   - 定时时长：0.1 s = 100 ms = 100,000 μs  
   - 选择 PSC = 8399 → 单位时间 100 μs  
   - 计数值 = 100,000 μs / 100 μs = 1000  
   - ARR = 计数值 - 1 = 999  

2. **CubeMX 配置**  
   - 选择定时器（如 TIM10）  
   - 设置 PSC = 8399  
   - 设置 Counter Period (ARR) = 999  
   - **NVIC 中使能** TIM1 update interrupt 和 TIM10 global interrupt（优先级可设为 5）  
   - 生成代码

3. **代码实现**  
   - 在 `main.c` 的 `HAL_Init();` 后调用：
     ```c
     HAL_TIM_Base_Start_IT(&htim10);
     ```
   - 在 `USER CODE BEGIN 4` 区域编写回调函数：
     ```c
     void HAL_TIM_PeriodElapsedCallback(TIM_HandleTypeDef *htim) {
         if (htim->Instance == TIM10) {
             HAL_GPIO_TogglePin(LD1_GPIO_Port, LD1_Pin);
         }
     }
     ```

4. **结果**：LD1 灯以 0.1 秒周期闪烁（注意：人眼可能看到快速闪烁或常亮效果）。

## 仿真调试技巧

- **断点**：鼠标左键点击行号左侧设置/取消（红色圆点）。
- **运行控制**：
  - Reset：复位
  - Run：全速运行（遇到断点停止）
  - Stop：手动停止
- **单步**：
  - Step Into：进入函数内部
  - Step Over：执行整行（不进入函数）
  - Step Out：跳出当前函数
- **Run to Cursor**：运行到光标所在行（需光标可到达）

> 注意：若目标设备不支持过多断点，需清除所有断点后重新设置。
