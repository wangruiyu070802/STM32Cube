## 1. 常见错误提醒

### 1.1 电源电压过高烧毁板子
- 板子 DC 口 **最高支持 18V**，插入 20V+ 电源会烧毁电源转换芯片、主芯片和仿真器。
- **注意**：实验室常用 12V 锂电池，充满电约 13.2V，在安全范围内；24V 绝对禁止。

### 1.2 删除代码时误删大括号导致编译错误
- 典型错误：删除了 `main` 函数或 `while(1)` 的大括号，编译后会在 `void SystemClock_Config()` 附近报错（如 125 行），并出现 12 个 error。
- **解决方法**：保持代码对齐，删除时留意括号配对，不要删掉必要的结构体大括号。

### 1.3 复制工程后添加文件路径错误
- 复制工程后，在 User 文件夹中添加 `.c` 文件时，默认路径是旧工程路径，导致找不到文件。
- **正确做法**：手动选择新工程对应的 `Drivers/User` 文件夹，只添加 `.c` 文件（不需要 `.h` 文件）。

## 2. ADC 基础知识

### 2.1 模拟信号与数字信号
- 自然界中的温度、声音等是连续变化的模拟信号，通过传感器转换为电压信号。
- 单片机只能处理数字信号（高电平 3.3V，低电平 0V），中间的连续电压称为模拟电压。
- **ADC（模数转换器）** 的作用：将模拟电压转换为数字量。

### 2.2 ADC 转换关系
- 假设模拟电压范围 0~3.3V，数字量范围 0~1000，则转换公式为：
  $$Y = \frac{X}{3.3} \times 1000$$
  其中 X 为模拟电压，Y 为数字量。
- STM32F4 的 ADC 分辨率为 12 位，所以数字量范围为 0~4095（$2^{12}-1$），公式变为：
  $$Y = \frac{X}{3.3} \times 4095$$

### 2.3 ADC 内部过程
- 采样 → 保持 → 量化 → 编码，完成一次 ADC 转换。

## 3. STM32F4 的 ADC 特性

### 3.1 主要参数
- **类型**：逐次逼近型 ADC。
- **分辨率**：最高 12 位（可配置为 6/8/10/12 位）。
- **时钟**：最大 36 MHz（可通过分频获得）。
- **转换时间**：采样时间 + 转换时间。
  - 转换时间：12 位模式下需 12 个 ADC 时钟周期。
  - 采样时间：可配置为 3~480 个 ADC 时钟周期。
- **参考电压**：VREF- = 0V，VREF+ = 3.3V，输入电压范围 0~3.3V（不可超过，否则损坏 ADC）。

### 3.2 通道与 ADC 数量
- STM32F401 只有 **1 个 ADC**（ADC1），STM32F407 有 3 个（ADC1/2/3）。
- 每个 ADC 有多个通道，引脚与通道对应：例如 PA0 是 ADC1/2/3 的通道 0，PA4 是通道 4，PA7 是通道 7。

### 3.3 触发方式
- **软件触发**：写代码启动转换。
- **外部触发**：通过定时器或外部信号触发（本课仅用软件触发）。

### 3.4 规则组与注入组
- **规则组**（Regular Group）：最多 16 个通道，按顺序轮流转换（排队）。
- **注入组**（Injected Group）：最多 4 个通道，可插入到规则组中（插队）。
- 规则组所有通道共用同一个数据寄存器，需要通过数组索引分离数据；注入组每个通道有独立寄存器，更方便。

### 3.5 转换模式组合
| 模式 | 单次/连续 | 扫描 | 应用场景 |
|------|----------|------|----------|
| 单次不扫描 | 单次 | 否 | 单通道单次测量 |
| 单次扫描 | 单次 | 是 | 多通道各测量一次 |
| 连续不扫描 | 连续 | 否 | 单通道连续采集波形 |
| 连续扫描 | 连续 | 是 | 多通道连续采集波形 |

### 3.6 数据对齐方式
- 12 位数据存储在 16 位寄存器中，有左对齐和右对齐。
- 推荐使用**右对齐**：读取值与实际值一致，无需移位。

## 4. ADC 配置与函数使用

### 4.1 CubeMX 配置要点（以 DMA 多通道为例）
- **Mode**：Independent mode（独立模式）。
- **Clock Prescaler**：设置分频系数（如 PCLK2/4 = 21MHz）。
- **Resolution**：12 bits。
- **Data Alignment**：Right alignment（右对齐）。
- **Scan Conversion Mode**：Enable（多通道必须开启）。
- **Continuous Conversion Mode**：Disable（单次扫描）。
- **Discontinuous Conversion Mode**：Disable。
- **Number of Conversion**：2（两个通道）。
- **Rank 设置**：分别指定通道号和采样周期（如通道4和7，采样周期 3 cycles）。
- **DMA Settings**：添加 DMA 传输，模式 Normal，数据宽度 Word（32位地址/16位数据）。
- **NVIC**：使能 ADC 全局中断（若使用 DMA 中断方式则需要，本课用 DMA 回调中断）。

### 4.2 常用 HAL 函数
- **启动转换**：`HAL_ADC_Start_DMA(&hadc1, pData, Length)` — 参数：ADC句柄、数据缓冲区指针、转换次数长度。
- **停止转换**：`HAL_ADC_Stop_DMA(&hadc1)`
- **等待转换完成**（非 DMA 方式）：`HAL_ADC_PollForConversion(&hadc1, timeout)`
- **中断回调**（DMA 完成后自动调用）：`HAL_ADC_ConvCpltCallback(ADC_HandleTypeDef* hadc)`

### 4.3 中断回调函数规范
- 在回调中判断来源：`if (hadc->Instance == ADC1)`
- 操作：调用 `HAL_ADC_Stop_DMA`，读取数据并转换电压，然后重新启动下一次 DMA 实现持续采集。

## 5. 实际项目：ADC 测电压并显示（DMA 方式）

### 5.1 硬件说明
- 板上有两个分压电路：
  - **外部电源（EX POWER）**：通过 10k:30k 分压，测得电压为实际值的 1/4，因此实际电压 = ADC值×4。
  - **受控电源（CONTROL POWER）**：通过 20k:30k 分压，测得电压为实际值的 2/5，因此实际电压 = ADC值×2.5。
- 两个电压分别接到 **PA4（ADC1_IN4）** 和 **PA7（ADC1_IN7）**。

### 5.2 软件实现步骤
1. **CubeMX 配置**（如上所述）。
2. **创建自定义文件**：`ADC_Convert.c` 和 `ADC_Convert.h`。
3. **定义全局变量**：
   ```c
   uint16_t ADC_Data[2];           // 存放两个通道的原始值
   float EX_Power, Control_Power;  // 计算后的电压值
   ```
4. **启动 DMA 转换**（在 main 初始化中）：
   ```c
   HAL_ADC_Start_DMA(&hadc1, (uint32_t*)ADC_Data, 2);
   ```
5. **编写中断回调函数**（在 `ADC_Convert.c` 中）：
   ```c
   void HAL_ADC_ConvCpltCallback(ADC_HandleTypeDef* hadc)
   {
       if(hadc->Instance == ADC1)
       {
           HAL_ADC_Stop_DMA(&hadc1);
           EX_Power = (float)ADC_Data[0] * 3.3f / 4095.0f * 4.0f;        // 通道4
           Control_Power = (float)ADC_Data[1] * 3.3f / 4095.0f * 2.5f;   // 通道7
           HAL_ADC_Start_DMA(&hadc1, (uint32_t*)ADC_Data, 2);            // 再次启动
       }
   }
   ```
   - **注意**：先乘后除提高精度，末尾加 `f` 表示单精度浮点。
6. **OLED 显示**：
   - 编写 `OLED_ShowFloat(x, y, float_num, int_len, float_len)` 函数（可使用 AI 生成）。
   - 在 `main.c` 的 `while(1)` 循环中调用显示函数，刷新电压值。

### 5.3 关键代码细节
- **数据类型**：`HAL_ADC_Start_DMA` 的 `pData` 要求是 `uint32_t*`（32位地址指针），但数据本身是 16 位，所以强制类型转换。
- **浮点运算精度**：先乘后除，例如 `ADC_Data[0] * 3.3f / 4095.0f` 避免除法截断。
- **电压换算**：
  $$V_{\text{实际}} = \frac{\text{ADC值} \times 3.3}{4095} \times \text{分压比}$$

## 6. 调试与优化

### 6.1 常见错误排查
- **ADC 数据异常大**：检查是否将 `pData` 错误地声明为 `uint32_t*` 却传给 16 位数组？实际应传 16 位数组的地址，但参数类型是 `uint32_t*`，强制转换即可，数据存储仍为 16 位。
- **OLED 显示乱码或不变**：检查浮点数显示函数是否正确，或是否在中断回调外读取了未更新的数据。
- **按键调整电压不灵敏**：因为按键是轮询方式，需要长按才能在 while 循环中检测到；可改用外部中断或增加定时器扫描。

### 6.2 上电安全设定
- 将 PWM 占空比初始值设为最大值（如 20），使输出电压降为 0V 或极低，避免上电直接高压输出烧毁负载。
- 代码中：`power_level = 20;`，然后 `__HAL_TIM_SET_COMPARE(&htim2, TIM_CHANNEL_1, power_level);`。

### 6.3 优化建议
- 使用 DMA 连续模式可减少中断次数，提高采样效率。
- 如需更高精度，可适当增加采样周期（如 28 或 480 cycles）。
- 若单片机主频需降低以匹配 ADC 最快时钟，可权衡 CPU 速度与 ADC 速度。
